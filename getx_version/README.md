# Student Authentication — GetX

مشروع Flutter مستقل لنظام مصادقة طلابي باستخدام GetX (`GetxController`, `Obx`, `GetMaterialApp`) مع MVC وRepository Pattern.

## التشغيل
```bash
flutter pub get
flutter run
```

## الشاشات
- تسجيل الدخول
- إنشاء حساب
- استعادة كلمة المرور
- تعيين كلمة مرور جديدة

## بيانات التجربة
- الرقم الأكاديمي: `123456789`
- كلمة المرور: `Student1`
- رمز استعادة كلمة المرور: `123456`

## توضيح
المستودع تجريبي ويخزن المستخدمين في الذاكرة فقط، ولا يتصل بخادم أو قاعدة بيانات. ستُفقد الحسابات الجديدة بعد إغلاق التطبيق. لا تستخدم هذا التخزين في تطبيق حقيقي.
